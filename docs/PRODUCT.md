# 产品概况

408 Guided Reader 是仍在开发的本地教材阅读器，当前以 Windows 桌面使用为主：本机运行服务，在 Chrome 或 Edge 中打开。它不是把 PDF 换成聊天窗口，也不是已经完成的通用教材平台。

## 原书是主体

用户读的是原始 PDF。OCR、目录、知识点、导读、AI 和习题交互都是叠在书周围的辅助层；机器生成内容不能替代原文，也不能让 AI 失败妨碍阅读。书中的来源位置应当能带用户回到原 PDF。

## 阅读与理解

- 页面按需准备 OCR 文字与位置，让扫描版教材可以选字、搜索、标记和定位。教材目录与知识点结构逐步建立；KnowledgePoint 是长期学习的单位，不是把每个术语都拆成独立卡片。
- Assistant 处理眼前局部的不懂：选中原文或可选的回答内容即可提问，回答里的内容还能继续向下解释。这类对话是临时的，不自动写入长期学习记录。
- Visual Region prototype 允许在原 PDF 上主动框选单个公式或图表区域；松手后可移动选框、拖边缘或四角调整，点击“解释”或按 Enter 确认后才裁图进入现有 Assistant，并立即清除选框、恢复阅读；Esc 取消。使用独立于阅读缩放的原 PDF 裁图，附近 OCR 和已有 KP 仅作辅助；没有 OCR 也能提问。普通 Assistant 只显示来源文字与解释，展开后提供一次紧凑来源行，按需打开原图；输入框从单行自适应增长。当前已人工验收通过，图片解释暂不保存为文字笔记。
- Master 用于知识点或小节的持续学习。对话和学习记录跨阅读会话保留；一次 AI 回答或一道题的对错，不会自行宣称用户已经掌握知识点。
- Reading Guide 帮用户理解一节为什么值得学、它与前后内容的关系。Inline Teaching 在原文旁补关键的中间逻辑。它们需要有教材依据；失败时仍保留原书和已有内容。
- Learning Memory 收纳用户明确选择留下的 Master 回答、已保存的解释，以及收藏的习题记录，并能返回原来的学习位置。它不是所有对话和做题历史的自动备份。

## 当前习题体验

Reader 2.0 的 Practice 已在特定版本的王道《计算机组成原理》真实 PDF 上经过人工使用验证。当前代码按目录、OCR 和原书答案保守生成同结构王道教材的 A/B/C/D 单选题；2026 年《数据结构》《操作系统》《计算机网络》已通过定向测试和真实浏览器 smoke，仍待人工使用验收。用户直接在原页选项上作答；提交后由程序对照教材官方答案判题，不让 AI 猜正确选项。提交前可以逐步要 Hint，提示所用材料不包含官方答案和解析。提交后可查看官方解析，并围绕 A/B/C/D 或整题进入 Master Review。收藏的题目出现在 Learning Memory 的习题学习记录里。

当前规则识别“本节习题精选 / 本节试题精选”与对应“答案与解析”，只发布能核对完整选项、唯一答案和解析的题目。不承诺适配其他 PDF、其他题型，也不宣称每道自动识别题都经过人工逐一核答案。做题和复盘不会自动改写知识点掌握状态。

按实际打开的习题节在后台尝试关联已有 KP 的能力及书库级扩展均已通过人工验收；网络、数据结构、组成原理已完成定向浏览器验证。关联使用当前书、所属小节或章节的已发布 KP，不限定样本教材；全书 OCR 更新不会单独排除仍有效的已发布 Knowledge Map。当前操作系统书库没有 KP，保持无关联。练习立即可用；明确匹配时左侧显示真实 KP 名称并可返回教材，再返回原题继续作答。没有合适候选或判断不了时不显示入口；匹配与明确无关联的结果会复用，模型失败以后可重试。不会创建 KP、强求覆盖或自动修改掌握状态。

朋友内测的多人服务端方案尚未实施；当前产品事实仍以 Windows 本地 Reader 为准。
