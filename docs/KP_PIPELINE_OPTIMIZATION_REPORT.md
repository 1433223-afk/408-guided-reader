# KP 生成与审查优化记录（2026-09-28）

## 问题与处理

- 计算机网络第四章原来约 71 秒：分节生成约 11 秒，两轮智谱整章审查约 59 秒。审查输入包含 374 个原文单元，约 4 万 token；模型有时把基础概念与后续可独立诊断的应用误判为重复。
- 现按最多四个语义窗口并行生成。一个大节内的多个窗口也可并行，进度仍按完成的小节显示。
- 整章审查保留候选首尾与最长原文单元的较长摘录，其余仅保留短提示。默认审查改用 DeepSeek；用户明确配置智谱时仍按配置。审查提示词明确区分“仅复述同一机制”和“后文有独立算法、表结构、计算或应用方法”。
- 审查中显示当前轮次、已等待时间和重试状态。轮次总数不能预知；若首轮要求修正，才会增加下一轮。
- 曾试验额外的疑似重复配对与复核，但在真实第四章中增加调用且结论不稳，已撤回；发布仍由原有整章审查和确定性校验把关。
