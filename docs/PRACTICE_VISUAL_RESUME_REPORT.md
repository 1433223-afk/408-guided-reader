## 同类根因检查与完整修复

用户要求修复一类原因，不能只给截图中的题目打补丁；该原则已写入开发入口。

根因是把“选项点击区域”当作“完整题目来源区域”。它同时影响当前题标识、跨页提示和题目裁图：题干页没有选项、选项后图在续页，以及中间只有题干或图表的页面，都可能被遗漏。现在 catalog 统一提供 `sourceRegions`，标识、跨页提示、定位和 Hint / Review 裁图共用它；选项命中仍只使用原有点击区域。

对现有四本王道 PDF 按文件身份去重检查，共 101 个习题节、2,090 道可发布单选题，其中 157 道跨页题；103 道含无选项的题目页，会触发原有标识遗漏和跨页提示遗漏（数据结构 27、网络 25、组成原理 27、操作系统 24）。这是共同错误的受影响题数，不是整个软件的 bug 数。

批量检查还发现组成原理 4.2.3 第 01 题的 OCR 行顺序把题干上方的前文表格夹进本题。现在在构造题干、选项文本和来源范围之前，按题干页面坐标排除上方前文，并保留同一行分拆 OCR 的小容差。
