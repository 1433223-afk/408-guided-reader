# Tablet 主动笔选字与打开教材（2026-10-19）

## 现场反馈与确认

延续 `codex/android-tablet-reader` / `d2a380f` 隔离工作区。用户确认 PDF 导入已能正常打开；新问题是点击教材后等 PDF 比电脑版慢，以及联想二代主动笔在 Android Chrome 中难以精确选字。手指选字正常。本轮未修改主线、正式学习库或 OCR 数据，也没有做手写、笔迹识别或 Practice 改造。

## 笔的问题

原 Tablet 只绕过 `pointerType=touch` 的鼠标选择函数。笔走鼠标路径：落笔创建空选区，轻点可能零字符，抬笔隐藏菜单；手指则经过长按分词与松手菜单。旧移动处理还缺少指针归属与接触判断，已在独立事件复现中观察到其他指针／笔悬停修改正在选择的内容；pointercancel 被当作正常结束。

实际 348 页教材副本已有约 36 万个 OCR cell，约 98% 为单字符，典型正文无需先重 OCR。新增 `cellIndexAt` 按触点所在或最近单元命中，避免最近插入边界在字的右半部分误选下一字。保留 OCR 的既有分组粒度和来源坐标，不能宣称所有合并单元都能逐字拆分。

新增独立 `tablet-pen.js` 控制器，绑定主笔尖与 pointerId，只在接触中扩选，按帧合并移动；正常抬笔 flush 最后坐标并显示现有菜单，异常取消只清理。App 保留初始单元，正反拖动都包含起始字；边界未变时不重建选区 DOM。普通鼠标、触摸与笔标记各自的选择归属，防止互相污染。

正在接触的笔优先于意外掌触；如果 Android 为笔同时派发 TouchEvent，仅在有笔 owner 时阻止该伴随流，并暂停手指长按控制器。没有使用 hover 时切换 `touch-action:none` 的做法：本机实际 TouchEvent 实验表明，在首个手指 pointerover/down 才恢复会阻断该次滚动。抬笔后的新手指手势仍保持原生行为。

## 打开教材的测量与修改

Chrome 155、真实本机 WLAN `192.168.43.65`、348 页／150,123,418 字节真实教材。普通同机 LAN 中书库冷启动约 232ms、重载约 131ms，点书到首 canvas 约 1 秒；这不能代表平板热点带宽。限速进一步发现首屏前约 350 个 64 KiB Range 请求，同时整本 200 流仍在下载。直接 PDF.js 对照也出现同类请求，说明主要在 document 初始化，不是 Reader 将 348 页全部渲染。PDF 根 Pages 直接包含 348 个页引用，启动的末页检查会遍历分散的页字典。

同一人工 4 MiB/s、50ms 延迟、相同禁缓存临时路由条件下进行参数对照，完整观测 worker 事件：

| 参数 | 首 canvas 出现 | 可见页绘制完成 | 实验记录的 PDF 接收量 |
| --- | ---: | ---: | ---: |
| 默认 64 KiB，流式与自动预取 | 9.562s | 10.854s | 38,564,570B |
| 256 KiB，禁流式和预取 | 24.234s | 24.560s | 91,403,162B |
| 16 KiB，禁流式和预取 | 7.037s | 7.390s | 7,794,002B |

增大块在该样本中明显更慢，未采用。只在 Tablet `getDocument` 中加入 `disableStream:true`、`disableAutoFetch:true`、`rangeChunkSize:16384`；Desktop 保持原参数。原 PDF、传输来源和 API 鉴权不变。这里只是单个真实教材、开发机限速对照，不宣称 Y900 同倍率改善；PDF.js 仍需许多初始化请求。公共 vendor 无缓存／压缩虽有成本，本轮没有扩大处理范围。

计时从书库「打开」开始，包含 Overview → 继续 PDF；接收量取可见 canvas 渲染完成时的 CDP dataLength 之和，包含重复 Range 与并发流，非唯一文件字节或链路层流量。原始测量以临时 stdin 脚本执行并输出到工具结果；之后如实转录到 ignored `.tmp/tablet-network-results-2026-10-19.json`，并整理 `.tmp/tablet-network-probe.mjs`。保存后的整理脚本未额外重跑，不将其称作原始采集文件。日后可在本实验工作区运行 `node .tmp/tablet-network-probe.mjs --mode defaults` 或 `--mode range16KiB` 复现，使用本次私密连接文件，输出另存 rerun 文件；不得把启动凭证写入报告。
