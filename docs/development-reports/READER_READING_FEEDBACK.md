# PDF 阅读反馈小修（2026-10-10）

## 核对结果

- 已有用户高亮、笔记和已保存解释；临时文字选区、框选以及“当前 / 续”导航标识有不同的保存语义。真实组成原理 PDF 第 20、174 页通过界面创建高亮和笔记，翻到远页触发页面回收再返回、关闭书重开、刷新浏览器均能恢复。本轮没有复现已保存标记丢失，也没有改造保存机制。
- Directory 已有明确入口、固定 304px、多级展开收起、当前项高亮和原文跳转；保留当前实现。折叠操作主要在 hover / 键盘聚焦时出现，初次使用可能不够显眼，是否调整留待人工判断。查阅了 2345 官方看图王首页及 PDF 阅读器介绍，能确认目录提取、页码跳转与历史记录，但没有获得足以核对当前看图王 PDF 目录操作的界面参考，因此没有凭想象复刻。
- 现有 Notes、文字选择、复制、右键问 AI、Visual Region 均可复用。笔记入口的动态名称此前只写“本页标记”，现在统一为“本页笔记与标记”；空列表仅补一句选字后右键的操作提示。没有修改 Assistant / Master 的对话持久化。
- 原有缩放为响应式页面宽度乘以百分比，基准页面宽度有 920px 上限；没有专门的正文适配或 PDF 柔和显示设置。

## 本轮改动

阅读显示菜单提供“适应宽度 / 适应整页 / 适应正文”及“柔和纸色”，人工体验后决定保留，不继续扩展。当前入口为缩放百分比旁的轻量下拉箭头。

“适应正文”只处理本页：将已渲染原页缩小取样，结合全部已有 OCR 行的水平范围，以两者并集加留白估计内容宽度，再用现有缩放和定位放大、居中。没有裁掉原页、改写 PDF、重做 OCR 或移动来源坐标；原页边缘仍可横向滚动查看。像素用于补足 OCR 没识别到的图表和页边内容。

柔和纸色仅给阅读区 canvas 加轻度亮度和纸色滤镜，可关闭；不反色、不影响原 PDF、OCR、标记几何或 AI 原书裁图。本机浏览器记住该显示偏好。

真实窄窗口还发现弹出工具获得焦点时会让外层 body 横向滚动，整个 Reader 向左移。外层页面现在禁止此类滚动，各页面自己的滚动容器继续正常工作；新增菜单的程序聚焦也不触发滚动。工具栏原有窄窗口隐藏文字层状态的规则还被通用按钮规则覆盖，挤出了最右侧工具；已修正选择器优先级，保留原有收纳方式。

## 暂不实现

- 小角度纠偏：现有 PDF 几何换算按 90° 旋转处理。只转 canvas 会错开文字、标记、框选和 Practice 命中；需要共享的小角度坐标变换及真实倾斜样本，本轮不引入处理管线。
- 全书自动边距：当前为用户主动点击、本页估计，百分比继续由现有阅读位置保存。扫描底色、边缘杂点或贯穿全宽的线条可能让检测保守地保持整页宽度；不承诺识别所有扫描书，也不自动逐页改缩放。极端长页仍受现有缩放范围限制。
- 更明显的目录折叠提示、更多笔记快捷方式及复杂显示设置，先保留建议，不重做目录或批注系统。
