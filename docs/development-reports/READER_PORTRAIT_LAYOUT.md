# Reader 竖屏阅读布局

2026-10-11 · 用户已确认人工验收通过，按本轮收口要求创建独立 Git checkpoint。

## 真实观察

使用《2026计算机组成原理》检查 1080×1920、900×1600 窗口。原布局在 1080px 下打开目录会进入导航模式并隐藏整个 PDF；900px 下 Practice 与 Master 同时打开时，PDF 只有约 513px、Master 约 207px，原书和对话都很拥挤。现有缩放和工具栏基本可用。

## 本轮改动

- 在百分比旁的阅读显示菜单加入“竖屏模式”，默认关闭，用户手动选择后保存在当前浏览器；窄窗口通过“···”打开同一菜单。
- 目录沿用原有内容、层级和定位。左边缘停留 180ms 临时打开，离开 400ms 后收起；进入目录取消收起，鼠标点击后离开仍能收起，键盘操作期间保留目录。可固定为 304px，固定后参与布局；普通模式行为保持原样。
- Assistant / Master 沿用现有对话区，在竖屏模式放到 PDF 下方，占用独立布局行。Practice Rail 仍在左侧，保留 resize、五个 Review 入口和原页选项交互；AI 不占 PDF 的横向宽度，也不覆盖它。
- 切换模式、固定或关闭目录时，沿用 PDF 锚点与渲染逻辑，保留靠近阅读区域上方的阅读位置和原缩放；高窗口不会以视口中心的另一页作为新位置。没有改变原 PDF 或来源坐标。
- 修复窄窗口“更多阅读工具”弹层被学习面板遮住的问题：在共享工具栏层级处处理，菜单打开时提高层级。

竖屏模式不随窗口尺寸强制开启。为保证 PDF 宽度，当前模式下不提供 AI 横向拖宽或全屏展开，普通模式恢复原有控件。切换模式保留已有百分比，过大的缩放仍可能需要水平滚动，可使用原有“适应宽度”。目录固定会占用 304px，连续导航时可固定，阅读时可取消。
