- **本地会话入口**：匿名首页原先会签发有效 Cookie。现在只有合法启动凭证或已有合法会话可以打开首页并建立会话；在所有请求分派前限制实际 loopback Host、同源 Origin，拒绝跨站浏览器请求。补上主线 `READY` 地址中的启动凭证，保留正常浏览器启动和刷新。非法非 ASCII token 不再使请求异常退出。API 测试验证了匿名/错误凭证、外来 Host/Origin 的拒绝，以及合法 Cookie 导入、删除的实际副作用。
- **仅智谱的习题路径**：移除 Practice 专属的智谱禁用；Hint 和 Master Review 只允许精确的 DeepSeek `deepseek-flash`、智谱 `GLM-5.3-Flash`。复用现有 Master 推理参数、作答记录和官方答案判题，没有复制实现或更改掌握语义。默认路由随可用凭据更新，显式开发配置仍保留。
- **KP 默认路由**：只配置智谱时不再默认寻找缺失的 DeepSeek；DeepSeek 可用时保留主线已有快速生成/审查默认。重新核查并行窗口进度、非铸造复习栏目、重复候选吸收后的复审、来源变化和发布边界，未新增按书名或章节号的补丁。没有扩大审查材料或绕过审查。
- **行间教学审查与返工**：真实失败中，审查曾把 recall 的严格前置知识约束套到普通预告和过渡提示上。明确只有 recall 要求全部知识已出现；其他类型仍要检查来源、成立条件、适时性和必要性。返工请求使用 source 在前、rework 在后的序列化顺序，避免反馈被长篇教材埋没。导读作者提示词和导读审查提示词均未改动。审查格式错误、来源校验失败和调用错误分开记录，成功发布清除旧 failure 字段。
- **PDF 异步渲染竞态与批注占位**：原先在等待 `getPage()` 时尚未登记任务，同页可能重复读取；滚动淘汰或分栏重排后，旧任务还可能写回。现在从读取开始登记每页请求，按请求身份、书籍代次、渲染代次及页面容器核对写回权限；视口淘汰同时取消在途请求，旧任务不能清理新任务或复活已淘汰页面。另外，Inline 批注改变内部预留空间却不改变 viewer 宽度，原 ResizeObserver 漏掉了它；900 像素真实浏览器新增尺寸检查复现旧页仍用旧尺度。批注开关现在统一重排、重新居中，并保留重排前阅读锚点。保留原缩放、来源几何和文字选择方案。
- **导入与资源边界**：临时文件创建纳入异常处理，空间预检及 ENOSPC/EDQUOT/Windows disk-full/SQLite FULL 返回明确的磁盘错误，API 为空间不足返回 507。权限错误不再报 PDF 损坏。导入检查有限几何和 UserUnit，OCR 与旧空页探测在分配位图之前检查渲染预算（3200 万像素、单边 16384）；正常教材仍使用原 200 DPI。故障注入验证创建、部分写入、fsync、blob 提交及数据库失败不留下半本教材。没有实际填满磁盘或渲染危险大页。
